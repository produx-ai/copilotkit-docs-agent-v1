### Integrate LangChain JS actions with CopilotRuntime

CopilotKit allows actions to return values from LangChain chains. This means you can call LangChain chains directly and return their results as part of your backend actions. Here's how to implement LangChain JS backend actions:

<Callout>
**Note** that `actions` can be either an array of actions or a function that takes `{ properties, url }` and returns an array of actions.

This allows you to **customize which backend actions are made available** according to the current frontend URL, as well as custom properties you can pass from the frontend.
</Callout>


```tsx title="/api/copilotkit/route.ts"
import { ChatOpenAI } from "@langchain/openai";
import { ChatPromptTemplate } from "@langchain/core/prompts";

const runtime = new CopilotRuntime({
  // ... existing configuration
  actions: ({properties, url}) => {
  actions: ({properties, url}) => {
    // `actions` here is a function receiving the current frontend url and custom properties,
    // and should return an array of action definitions:
    // `url` is the current URL on the frontend application.
    // `properties` contains custom properties you can pass from the frontend application.

    return [
      {
        name: "generateJokeForTopic",
        description: "Generates a joke for a given topic.",
        parameters: [
          {
            name: "topic",
            type: "string",
            description: "The topic to generate a joke about.",
            required: true,
          },
        ],
        handler: async ({topic}: {topic: string}) => {
          const prompt = ChatPromptTemplate.fromMessages([
            [
              "system",
              "You are a witty comedian. Generate a short, funny joke about the given topic. But make it sound like a pirate joke!",
            ],
            ["user", "Topic: {topic}"],
          ]);
          const chain = prompt.pipe(new ChatOpenAI());
          const result = await chain.invoke({ topic });
          return { joke: result.content };
        },
      },
    ]
  }
});
    ]
  }
});

// ... rest of your route definition
```

</Step>

After adding the LangChain JS action, test it by asking the copilot to generate a joke about a specific topic. Observe how it uses the LangChain components to generate the response.
