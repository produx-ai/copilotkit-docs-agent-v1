## CrewAI-specific Premium context

- **CrewAI Agent Orchestration Hooks (Early Access):** Premium features include hooks to orchestrate multi-agent CrewAI workflows. Use them to manage crew role assignments and task routing alongside CopilotKit’s headless UI and observability tools.
- **CrewAI examples:** See the CrewAI crews starter in the examples (`examples/coagents-starter-crewai-crews`) for a reference implementation of agent-powered apps using CopilotKit Premium features.

### How Premium helps CrewAI crews
Premium extensions provide advanced orchestration for self-hosted or cloud-hosted CrewAI agents, enabling fully headless UI integration, crew role-aware messaging, and observability for crew task execution.
